# THM Label Studio Professional — исходный проект, Developer Preview 0.1

Это **реальный исходный проект WPF**, но **не готовый аналог BarTender** и не собранный .exe. Для сборки нужен Windows 11 x64, Visual Studio 2022 с поддержкой .NET 10 или установленный .NET 10 SDK с WPF-поддержкой.

## Сборка

1. Установить .NET 10 SDK и workload **.NET desktop development** в Visual Studio (с поддержкой .NET 10).
2. Открыть `THM_Label_Studio_Professional.slnx`.
3. Собрать `Release | x64` (или `Any CPU`) и запустить проект `LabelStudio.App`.
4. Либо в PowerShell выполнить `dotnet run --project .\src\LabelStudio.App\LabelStudio.App.csproj`.
5. Для публикации: `dotnet publish .\src\LabelStudio.App\LabelStudio.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\publish`.

## Реализовано в стартовом проекте

- Графический WPF-холст в миллиметрах; прямоугольники и текст.
- Выбор объектов, перетаскивание мышью, изменение координат/свойств; добавление и удаление.
- Сохранение/открытие макетов в JSON.
- CSV с именованными столбцами и привязкой поля текста к столбцу; просмотр записей по одной.
- Базовая печать текущего макета через установленный **Windows**-драйвер, с подтверждением пользователя.
- Интерфейс будущих адаптеров и каталог языков Zebra (ZPL), TSC (TSPL), CAB (JScript), Godex (EZPL), Weidmüller (THM RAW).
- Эталонный PowerShell-код v0.11 и реальные RAW-образцы приложены **только как справочные материалы**, не исполняются новым приложением.

## Ещё НЕ реализовано

- Печать THM RAW из C# (не перенесена, избегаем опасных неподтверждённых изменений).
- Генерация и отправка ZPL, TSPL, JScript, EZPL; обнаружение и управление принтерами.
- Штрихкоды / QR / Data Matrix; изображения и профессиональный редактор с масштабом, поворотами, сеткой, слоями, направляющими.
- Импорт XLSX, SQL, полноценная пакетная печать, диспетчер с паузой и возобновлением.
- Режим непрерывного материала; аппаратные параметры подачи и калибровка.
- Автоматизация, API, установщик, драйвер Windows.

**Ограничение:** текущая Windows-печать передаёт визуализацию выбранному драйверу и не задаёт аппаратный режим рулона. Проверьте носитель и параметры драйвера перед отправкой задания.

## Контроль безопасности

- Никаких непроверенных RAW-команд для THM MultiMark в новом приложении.
- Архив `legacy-reference` нужен для последующего точного переноса проверенного протокола v0.11.
- Принтероспецифичные адаптеры показываются как `not implemented`; мы не выдаём их за работающие.

## Логика развития без переписывания ядра

`LabelDocument` (мм) → data binding → render → `IPrinterAdapter` → spool/USB/LAN. Все печатающие адаптеры должны использовать единую модель размеров и независимо тестироваться на реальном оборудовании.
