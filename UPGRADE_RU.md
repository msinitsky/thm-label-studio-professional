# THM Label Studio Professional — Designer Preview 0.3

## Изменения
- Меню и две классические панели инструментов по образцу профессиональных редакторов этикеток.
- Большая голубая рабочая зона и центрированный макет с тенью.
- Компактный список объектов слева и свойства справа; разделители изменяют ширину панелей.
- Русские надписи интерфейса, строка состояния, масштаб и настройки сетки.
- Сохранены обработчики создания, перемещения, дублирования, удаления, открытия и сохранения объектов, CSV и печати Windows.

## Важно
Это обновление пользовательского интерфейса, не копия BarTender. Адаптеры Zebra, TSC, CAB, Godex и THM RAW, QR и DataMatrix в WPF-версии пока не реализованы.
Сборка Windows не проверена в Linux-среде.

## Обновление через GitHub
1. Распаковать содержимое ZIP в корень локального репозитория (не трогать .git).
2. Выполнить: git add -A; git commit -m "Classic designer interface 0.3"; git push origin main
3. Открыть Actions, дождаться результата, скачать артефакт.
