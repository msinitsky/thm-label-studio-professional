# THM Label Studio Professional — Ribbon Preview v0.5

## Добавлено

- Выделенный объект получает синий маркер изменения размеров в правом нижнем углу.
- Изменение ширины и высоты объекта перетаскиванием мышью (в пределах этикетки).
- При включённой привязке размер округляется до 1 мм.
- Новая вкладка «Формат объекта»: шесть команд позиционирования относительно самой этикетки.
- Ctrl+S — сохранение, Ctrl+O — открытие; действующие Ctrl+D, Del и стрелки сохранены.
- Клик по свободной области холста снимает выделение.

## Установка

Распаковать содержимое архива в корень существующего Git-репозитория, **не удаляя .git**.

```powershell
git add -A
git commit -m "Ribbon editor 0.5: resize handles and alignment"
git push origin main
```

Сборка запускается автоматически через GitHub Actions. Проверьте, что **Build Windows x64** завершилась успешно, прежде чем запускать обновление.

## Проверка

1. Создать текст, выделить, потянуть синий квадрат внизу справа — меняются размеры объекта.
2. Перейти во вкладку «Формат объекта» и применить горизонтальное/вертикальное выравнивание.
3. Выключить привязку на вкладке «Вид», проверить дробные миллиметры.
4. Сохранить макет, закрыть и загрузить — геометрия должна сохраниться.
5. Проверить, что печать по-прежнему запускается только через стандартный Windows-драйвер.

**Важное:** эта версия не включает драйверы Zebra/TSPL/CAB/Godex/THM RAW и не заявляет поддержку их специальных языков. Проверка компиляции и интерактивного поведения на Windows выполняется через ваш GitHub Actions и компьютер.
