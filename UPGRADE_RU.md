# Обновление 0.8

Добавлен импорт Excel XLSX (ClosedXML), сохранён CSV. Добавлена печать диапазона записей через Windows-драйвер с управляемой паузой, предпросмотром, журналом и ограничением до 500 заданий. Для QR, Code 128 и Data Matrix значения берутся из указанного поля источника данных.

Это тестовый диспетчер Windows, без автоматического определения физически напечатанных этикеток. Пауза не отменяет задания уже переданные Windows. После ошибки перед повторным запуском необходимо проверить очередь и фактически напечатанные этикетки.

Компиляция и аппаратные испытания пока не выполнены. Для сборки: распаковать поверх существующего Git-проекта без удаления .git; `git add -A; git commit -m "Ribbon 0.8 Excel and batch dispatcher"; git push origin main`.
