# Обновление до Ribbon v0.6

1. Закрой программу. Распакуй все файлы архива непосредственно в папку Git-репозитория `thm-label-studio-professional` (не удаляй `.git`).
2. Выполни в PowerShell:

```powershell
git add -A
git commit -m "Ribbon 0.6: QR, Code128, embedded images"
git push origin main
```

3. Перейди в GitHub Actions и скачай новый ZIP из Artifacts после успешной сборки.

## Новые инструменты

На вкладке **Вставка** доступны **Code 128**, **QR-код** и **Изображение**. Кодовые значения задаются в правой панели «Содержимое». Для переменных значений укажи имя столбца CSV в поле «Поле CSV».

Изображения размером до 10 МБ встраиваются в JSON-шаблон (base64): перенос макета между компьютерами не требует сохранения исходного файла картинки.

QR и Code128 рендерятся библиотекой ZXing.Net, которая загружается через NuGet при сборке. Зависимость добавлена в csproj.

## Испытание

1. Добавь QR и Code128, отредактируй значение, проверь различие кодов после изменения.
2. Импортируй изображение, сохрани и снова открой макет.
3. Загрузи sample.csv, привяжи QR к полю из CSV, переключай строки и проверь, что QR меняется.
4. Принтер THM MultiMark через RAW **ещё не подключён**: доступна только общая печать через установленный драйвер Windows.

Изменения не тестировались физически на Windows. Не печатай большую партию без одиночного теста и проверки сканером.
