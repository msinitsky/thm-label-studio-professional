# THM Label Studio Professional — v0.7

Добавлено: Data Matrix ECC200 (ZXing.Net), форматирование текстовых объектов (жирный, курсив, подчёркивание, семейство шрифта, выравнивание) через Ribbon и панель свойств. Свойства сохраняются в JSON, копирование объектов переносит форматирование.

## Установка
Распакуйте **содержимое** архива в корень существующего Git-репозитория, не удаляя `.git`.

```powershell
git add -A
git commit -m "Ribbon v0.7: Data Matrix and text formatting"
git push origin main
```

GitHub Actions создаст сборку Windows x64. Проверьте вкладку «Вставка» и «Главная», сохранение и повторное открытие JSON с Data Matrix, CSV-подстановку, отображение кириллицы в тексте.

**Внимание:** исходники подготовлены, но Windows-компиляция и печать не выполнялись. THM RAW и прочие специализированные принтерные языки всё ещё не включены.
