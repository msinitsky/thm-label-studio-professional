# THM Label Studio Professional — Ribbon Preview 0.4

## Что изменено

Интерфейс переработан в стиле современных офисных приложений: верхняя лента вкладок «Файл», «Главная», «Вставка», «Макет», «Данные», «Печать», «Вид» с группами команд. Быстрые кнопки «Создать», «Открыть», «Сохранить» доступны постоянно.

Все работающие обработчики команд сохранены. Элементы QR, штрихкодов и изображений пока показаны отключёнными: это запланированные функции, а не готовая поддержка. Расположение панелей объектов/свойств и WYSIWYG-холста оставлено прежним.

## Обновление GitHub

Распакуй ZIP **с содержимым в корень существующего репозитория**, сохрани `.git` и выполни:

```powershell
git add -A
git commit -m "Ribbon UI 0.4"
git push origin main
```

На GitHub Actions будет собран Windows x64 ZIP. Исходник XAML проверен как XML, но Windows-компиляция требует проверки в GitHub Actions.
